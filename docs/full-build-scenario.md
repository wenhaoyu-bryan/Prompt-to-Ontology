# Full Build Scenario

## Why this exists

Clean Build Mode lets users start from an empty graph, but the single-source Data Pipeline flow is tedious for building a complete ontology. The Full Build Scenario orchestrates multiple sample datasets into a single reviewable Build Plan with proper dependency ordering.

---

## Data Sources

The Pet Food full build uses four CSV files from `sample-data/pet-food/`:

| Source | Object Types | Description |
|---|---|---|
| `pet_food_products.csv` | PetFoodProduct, Brand, Species, LifeStage | Product catalog with nutrition values |
| `pet_food_ingredients.csv` | Ingredient | Ingredient definitions with allergen flags |
| `product_ingredients.csv` | — (links) | Product-to-ingredient CONTAINS relationships |
| `risk_rules.csv` | RiskRule | Domain risk rules with conditions |

---

## Build Stages

The Build Plan organizes candidates into four ordered stages:

### Stage 1: Reference Objects
Brand, Species, LifeStage — foundational entities that other objects depend on.

### Stage 2: Core Objects
PetFoodProduct, Ingredient, RiskRule — main ontology entities.

### Stage 3: Relationships
MADE_BY, CONTAINS, TARGETS_SPECIES, SUITABLE_FOR — entity connections.

### Stage 4: Rule-Generated Evidence
TRIGGERS_RISK — evidence edges generated by the rule engine.

---

## Validation

The Build Plan includes cross-source validation:

- Duplicate object IDs
- Missing source/target references in links
- Empty required fields
- Schema constraint violations

Errors and warnings are shown per-stage and in the overall summary.

---

## Review Queue Integration

The Build Plan can be submitted to the Review Queue via:

```http
POST /api/review/from-build-plan/{build_plan_id}
```

Review items preserve build plan metadata:

```json
{
  "_stage_id": "core_objects",
  "_stage_order": 2
}
```

---

## Apply Order

When applying a full build review batch, objects are applied before links:

1. `IMPORT_OBJECT_CANDIDATE` (sorted by stage_order)
2. `IMPORT_LINK_CANDIDATE` (sorted by stage_order)
3. Other item types

This prevents link application failures due to missing endpoint nodes.

---

## How to Demo It

### From Clean Build Mode

1. Settings → Reset to Clean Build
2. Data Pipeline → "Build Full Pet Food Ontology" card
3. Click "Start Full Build Scenario"
4. Review the Build Plan preview (stages, candidates, validation)
5. Click "Submit to Review Queue"
6. Review Queue → Approve All → Apply All
7. Object Explorer / Graph Explorer show the complete ontology

### From Seeded Demo Mode

1. Data Pipeline → "Build Full Pet Food Ontology" card
2. The scenario works regardless of current graph state
